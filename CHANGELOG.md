## [0.1.0] - 2026-11-17

### Added

- Live Scanner — Detects nearby networks, encryption and signal strength using Scapy wrappers
- Smart Wordlists — Generates targeted dictionaries from SSID, leaks, patterns and local AI hints
- Safe Simulation — Runs full brute-force demos in-memory without touching real networks
- Android APK — Builds a native mobile app via Buildozer with location and WiFi permissions
- Ethics Guard — Mandatory consent checklist and legal warnings before any live action
- PDF Reports — Creates professional audit reports with findings, timelines and recommendations
- AI Predictor — Local pattern model suggests likely passwords based on network metadata
- Handshake Analyzer — Parses captured files for offline cracking simulation and validation
